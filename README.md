## 公司简介

![公司架构图](assets/company-structure.svg)


苏州弓海贸易有限公司是专业工业流体设备（磁力泵/换热器/过滤器）代理与服务商。台湾母公司成立于1983年，拥有40年行业经验。代理的国际知名品牌包括 **INNOMAG、DAIDO、KUROSE、WOOAM、PTCXPUMP、Filter Plus** 等。

## 行业应用

### 半导体 / 电子
晶圆厂湿法生产中的超纯化学品（酸碱溶液、显影液，光刻胶等）输送，需要零泄漏与高洁净度。常用 INNOMAG 无轴封磁力泵或衬氟磁力泵。

- 晶圆厂超纯化学品输送
- 液晶面板光刻胶输送
- PCB 蚀刻液/显影液循环

### 化工 / 电镀
强酸（盐酸、硫酸、氢氟酸）、强碱（氢氧化钠）及各类有机溶剂的输送，是磁力泵最典型的应用场景。常用 PTCXPUMP 工程塑料磁力泵。

- 强酸强碱介质输送
- 化工园区集中供液
- 电镀工艺槽液循环

### 制药 / 食品
制药与食品生产需要符合 GMP 标准的设备，接触物料的泵体与管路材质要求高，需要可清洗、耐腐蚀、无析出。常用不锈钢磁力泵或卫生级泵。

- 符合 GMP 标准的洁净输送
- 高纯度原料输送
- 注射用水/纯化水循环

### 环保 / 废水处理
工业废水含酸碱或有机物，需要耐腐蚀泵浦进行废液输送与处理。常用工程塑料磁力泵或气动隔膜泵。

- 酸碱废水输送
- 化学药剂添加与计量
- 中水回用与再利用

### 石油 / 能源
石化与能源行业的流体输送常含碳氢化合物，对泵的密封性能要求极高。常用无轴封磁力泵或屏蔽泵。

- 炼化工艺流体输送
- 加氢站氢气增压配套
- 离岸风电变压器冷却循环
