#### Über uns

![Unternehmensstruktur](assets/company-structure.svg)

Suzhou Gonghai Trading Co., Ltd. ist ein professioneller Händler und Dienstleister für industrielle Fluidtechnik: dichtungslose Magnetpumpen, Wärmetauscher, Filter. Unsere Muttergesellschaft in Taiwan wurde 1983 gegründet, was uns **40 Jahre Branchenerfahrung** verleiht. Wir vertreten internationale Marken: **INNOMAG, DAIDO, KUROSE, WOOAM, PTCXPUMP, Filter Plus**.
