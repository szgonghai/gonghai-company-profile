#### 公司簡介

![公司架構圖](assets/company-structure.svg)

蘇州弓海貿易有限公司是專業工業流體設備（磁力泵/熱交換器/過濾器）代理與服務商。台灣母公司成立於1983年，擁有40年行業經驗。代理的國際知名品牌包括 **INNOMAG、DAIDO、KUROSE、WOOAM、PTCXPUMP、Filter Plus** 等。

#### 行業應應

### 半導體 / 電子
- 晶圓廠超純化學品輸送
- 液晶面板光刻膠輸送
- PCB 製程蝕刻液循環

### 化工 / 電鍍
- 強酸強鹼介質輸送
- 化工園區集中供液
- 電鍍工藝槽液循環

### 製藥 / 食品
- 符合 GMP 標準的潔淨輸送
- 高純度原料輸送
- 注射用水循環

### 環保 / 廢水
- 工業廢水處理
- 化學品添加
- 中水回用

### 石油 / 能源
- 煉化製程流體輸送
- 加氫站配套
- 離岸風電冷卻
