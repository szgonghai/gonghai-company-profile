## 🏛️ 公司簡介

<div align="center">
  <img src="assets/company-structure.svg" alt="公司架構" width="700" />
</div>

蘇州弓海貿易有限公司是**專業工業流體設備代理與服務商**。

- **40 年歷史**:1983 年台灣母集團成立,2008 年蘇州弓海貿易有限公司
- **團隊規模**:20+ 蘇州團隊 + 數十人台灣母集團
- **客戶規模**:服務客戶上千家
