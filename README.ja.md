#### 会社案内

![会社構造](assets/company-structure.svg)

蘇州弓海貿易有限公司は、シールレスマグネットポンプ、熱交換器、フィルターなどの工業用流体機器の専門ディストリビューター兼サービスプロバイダーです。台湾の親会社は1983年に設立され、**40年の業界経験**を有します。**INNOMAG、DAIDO、KUROSE、WOOAM、PTCXPUMP、Filter Plus** などの国際的な有名ブランドを取り扱っています。
